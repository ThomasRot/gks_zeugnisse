Zeugnis-Generator

Georg-Kerschensteiner-Schule

Laden Sie die Vorlage herunter, füllen Sie sie aus, laden Sie sie wieder hoch & erzeugen Sie ein PDF. Alles passiert lokal in Ihrem Browser – es werden keine Daten hochgeladen.

1
Vorlage herunterladen

Eine Excel-Datei (.xlsx) mit einer Zeile je Fähigkeit. Kann auch mit OpenOffice oder LibreOffice geöffnet werden.

2
Ausgefüllte Datei hochladen

Wählen Sie Ihre ausgefüllte Excel-Datei aus (.xlsx).

3
PDF erzeugen

Laden Sie das PDF herunter.
