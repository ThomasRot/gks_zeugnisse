Zeugnis-Generator

Georg-Kerschensteiner-Schule

Laden Sie eine oder mehrere ausgefüllte Excel-Dateien hoch & erzeugen Sie die Zeugnis-PDFs. Alles passiert lokal in Ihrem Browser – es werden keine Daten hochgeladen.

1
Ausgefüllte Dateien hochladen

Wählen Sie eine oder mehrere ausgefüllte Excel-Dateien aus (.xlsx). Die Vorlage erhalten Sie von der Schulleitung.

2
PDFs erzeugen

Ein Zeugnis wird direkt als PDF heruntergeladen, mehrere gebündelt als ZIP-Datei.
